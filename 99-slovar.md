# Словарь

Все термины книги по алфавиту: сначала латиница, затем кириллица. В скобках — английское название: так термин проще найти в инструкциях, программах и видеоуроках. Слова, выделенные жирным внутри объяснений, тоже есть в словаре.

| Термин | Что это значит |
| --- | --- |
| **BPM** (beats per minute) | «долей в минуту», единица **темпа**. 60 BPM — одна **доля** в секунду. |
| **Gate** (gate) | в Circuit Tracks: сколько звучит нота на шаге, то есть её **длительность**. Короткий gate — отрывисто, длинный — протяжно. |
| **LFO** (low-frequency oscillator) | низкочастотный генератор в **синтезаторе**: медленно и ритмично «покачивает» **фильтр**, высоту или громкость. |
| **MIDI** (Musical Instrument Digital Interface) | стандартный «язык», на котором электронные инструменты и компьютеры передают команды: какая нота нажата, с какой силой, когда отпущена. Звука не содержит. |
| **Probability** (probability) | в Circuit Tracks: вероятность, с которой нота на шаге прозвучит при очередном повторе; делает **луп** менее механичным. |
| **Velocity** (velocity) | сила нажатия на клавишу или пэд. Влияет на громкость, а иногда на яркость звука; способ задать **динамику**. |
| **Аккорд** (chord) | три и больше ноты, сыгранные одновременно. Самый важный вид — **трезвучие**. |
| **Акцент** (accent) | удар, сыгранный громче соседних. Обычно акцентируют **доли**, а удары между ними играют тише. |
| **Бас** (bass) | самая низкая **партия**. Её больше чувствуешь телом, чем слышишь; она подсказывает, какой сейчас **аккорд**. |
| **Бемоль** (flat, ♭) | знак «на **полутон** ниже». `Ми♭` — клавиша сразу слева от `ми`. |
| **Биения** (beating) | дрожание громкости, когда звучат две близкие по высоте ноты: волны то усиливают, то гасят друг друга. Из-за них **диссонанс** звучит резко. |
| **Бит** (beat, drum pattern) | барабанная партия, ритмический каркас композиции: **бочка**, **малый барабан**, **хай-хэт** и т. п. |
| **Бочка** (kick drum) | бас-барабан, самый низкий барабан, «бум» в ритме. На установке играется педалью. |
| **Буквенные названия** (letter names) | обозначение нот латинскими буквами: `C` — `до`, `D` — `ре`, `E` — `ми`, `F` — `фа`, `G` — `соль`, `A` — `ля`, `B` — `си`. Приняты на электронных инструментах, в программах и англоязычных инструкциях. |
| **Вариация** (variation) | изменённая версия готового **паттерна** или **фразы**: основа та же, часть нот или ритма другая. |
| **Вопрос и ответ** (call and response) | пара **фраз**: первая заканчивается не на **тонике** и звучит незавершённо, вторая возвращается на тонику. |
| **Восьмая** (eighth note) | половина **доли**: две восьмых на долю, восемь на **такт**. Считается «раз-и, два-и…». |
| **Гамма** (scale) | все ноты **лада**, сыгранные подряд снизу вверх или сверху вниз. |
| **Гармония** (harmony) | то, какие ноты звучат одновременно и как **аккорды** сменяют друг друга. Создаёт фон и настроение под **мелодией**. |
| **Громкость** (volume, loudness) | насколько сильны колебания звука. |
| **Грувбокс** (groovebox) | электронный инструмент «всё в одном»: **синтезатор**, **драм-машина** и **секвенсор** в одном корпусе. Circuit Tracks — грувбокс. |
| **Децибел** (decibel, дБ) | единица громкости на логарифмической шкале: +10 дБ — мощность звука в 10 раз больше, на слух примерно вдвое громче. Разговор — около 60 дБ, концерт — 100–110 дБ; долгое прослушивание громче 85 дБ вредит слуху. |
| **Диез** (sharp, ♯) | знак «на **полутон** выше». `До♯` — клавиша сразу справа от `до`. Электронные инструменты обычно называют чёрные клавиши через диезы. |
| **Динамика** (dynamics) | разница в силе звучания нот: тихие проходящие и громкие опорные. В Circuit Tracks задаётся через **Velocity**. |
| **Диссонанс** (dissonance) | созвучие, которое звучит резко и напряжённо (например, две соседние клавиши). Противоположность — **консонанс**. |
| **Длительность** (duration) | сколько времени звучит нота. В Circuit Tracks задаётся через **Gate**. |
| **До мажор** (C major) | **мажор** с **тоникой** `до`: `до`, `ре`, `ми`, `фа`, `соль`, `ля`, `си` — все белые клавиши. |
| **До минор** (C minor) | **натуральный минор** с **тоникой** `до`: `до`, `ре`, `ми♭`, `фа`, `соль`, `ля♭`, `си♭`. Лад урока в главе 6. |
| **Доля** (beat) | равномерный пульс музыки, под который хочется хлопать. 4 доли = 1 **такт**; на Circuit Tracks каждая доля делится на 4 **шага**, доли начинаются на шагах `1, 5, 9, 13`. |
| **Драм-машина** (drum machine) | электронный инструмент, играющий барабанные партии по записанной программе. |
| **Задержка** (delay) | эффект эха: звук повторяется несколько раз, постепенно затихая. В Circuit Tracks включается кнопкой FX. |
| **Закрытый хэт** (closed hi-hat) | **хай-хэт** с сомкнутыми тарелками: короткий тихий «тс». Заполняет промежутки между **бочкой** и **малым**. |
| **Интервал** (interval) | расстояние между двумя нотами: **секунда**, **терция**, **кварта**, **квинта**, **октава** и другие. Название — латинское порядковое числительное (вторая, третья…). |
| **Кварта** (fourth) | интервал в 5 полутонов (`до`–`фа`), отношение частот 4 : 3. Консонанс. |
| **Квинта** (fifth) | **интервал** в 7 **полутонов** (`до`–`соль`), отношение частот 3 : 2. После октавы — самое слитное созвучие. |
| **Кластер** (cluster) | несколько соседних клавиш, нажатых вместе: сплошной **диссонанс**. |
| **Клэп** (clap) | звук хлопка в ладоши. Ставится туда же, где **малый барабан**, вместо него или вместе с ним. |
| **Консонанс** (consonance) | созвучие, в котором звуки сливаются и звучат спокойно. У консонансов простые отношения частот: 2 : 1, 3 : 2, 4 : 3, 5 : 4, 6 : 5. |
| **Контур** (contour) | линия, которую рисует **мелодия**, если отмечать высоту каждой ноты точкой: вверх, вниз или на месте. |
| **Крэш** (crash cymbal) | тарелка с громким всплеском, ставит акцент в начале новой части. |
| **Лад** (mode, key) | набор нот (обычно 7 из 12), из которых строится музыка, и главная нота среди них — **тоника**. Самые распространённые — **мажор** и **натуральный минор**. |
| **Ладовая окраска** (mood, character) | настроение, которое лад обычно создаёт: мажор чаще звучит светло и уверенно, натуральный минор — грустно или напряжённо. Привычка европейской музыки, а не строгое правило: многое зависит от темпа и ритма. |
| **Лид** (lead) | яркий солирующий звук синтезатора, которым играют главную **мелодию**. |
| **Логарифмическая шкала** (logarithmic scale) | шкала, на которой равные шаги — это равные умножения, а не прибавления. Так ухо воспринимает высоту (октава — всегда ×2) и громкость (децибелы). |
| **Луп** (loop) | короткий музыкальный фрагмент, повторяющийся по кругу без остановки. |
| **Ля минор** (A minor) | **натуральный минор** с тоникой `ля`: `ля`, `си`, `до`, `ре`, `ми`, `фа`, `соль` — все белые клавиши. |
| **Мажор** (major) | **лад** с порядком шагов тон, тон, полутон, тон, тон, тон, полутон. Обычно звучит светло. |
| **Макро-ручки** (macro knobs) | восемь ручек Circuit Tracks, на которые в каждом **пресете** выведены самые полезные настройки звука. |
| **Малый барабан** (snare drum) | резкий хлёсткий «тыщ». Обычно звучит на 2-ю и 4-ю **доли**, чередуясь с **бочкой**. |
| **Мелодия** (melody) | последовательность нот разной высоты, которую можно напеть; состоит из **фраз**. |
| **Метроном** (metronome) | прибор или приложение, ровно щёлкающее на каждую **долю** в заданном **темпе**. |
| **Монохорд** (monochord) | древний учебный прибор: одна струна над ящиком и подвижная подставка, делящая её на части. На нём пифагорейцы нашли простые отношения октавы (2 : 1), квинты (3 : 2) и кварты (4 : 3). |
| **Мьют** (mute) | временное выключение дорожки, чтобы она не звучала. В Circuit Tracks делается в режиме Mixer. |
| **Натуральный минор** (natural minor) | самый простой вид минорного **лада**: тон, полутон, тон, тон, полутон, тон, тон. От `до`: `до`, `ре`, `ми♭`, `фа`, `соль`, `ля♭`, `си♭`. Обычно звучит грустно. |
| **Неустойчивая нота** (unstable tone) | **ступень** лада, на которой мелодия не может закончиться: 2, 4, 6 и 7-я. Слух ждёт продолжения. |
| **Нота** (note) | звук определённой высоты и его название: `до`, `ре`, `ми`, `фа`, `соль`, `ля`, `си` (или `C`, `D`, `E`, `F`, `G`, `A`, `B`). |
| **Огибающая** (envelope) | блок **синтезатора**, задающий, как звук нарастает после нажатия и затухает после отпускания. |
| **Октава** (octave) | расстояние от ноты до следующей ноты с тем же названием, 12 **полутонов**; частота растёт вдвое. Так же называют участок клавиатуры между двумя `до`. |
| **Осциллятор** (oscillator) | блок **синтезатора**, создающий исходную волну нужной высоты. |
| **Открытый хэт** (open hi-hat) | **хай-хэт** с разомкнутыми тарелками: длинный шипящий «тссс». |
| **Партия** (part) | то, что играет один инструмент или одна дорожка: барабаны, **бас**, **мелодия**. |
| **Паттерн** (pattern) | записанная в **секвенсор** партия одной дорожки, обычно длиной в один **такт**, которая повторяется. |
| **Пауза** (rest) | момент тишины в партии; на секвенсоре — пустой **шаг**. |
| **Пифагорова комма** (Pythagorean comma) | крошечная разница (около 1,4 % по частоте) между 12 квинтами подряд и 7 октавами. Из-за неё звукоряд из чистых квинт не замыкается в круг. |
| **Полутон** (semitone) | самое маленькое расстояние между нотами: две соседние клавиши без пропуска (`до`–`до♯`, `ми`–`фа`, `си`–`до`). В октаве 12 полутонов. |
| **Пресет** (preset, patch) | сохранённый под именем набор настроек синтезатора: «мягкий бас», «яркий лид». |
| **Пэд** (pad) | 1) резиновая кнопка на панели инструмента; 2) мягкий тянущийся звук синтезатора для аккордов. |
| **Равномерная темперация** (equal temperament) | система настройки, в которой октава поделена на 12 одинаковых полутонов (каждый — примерно ×1,06 по частоте). Пифагорова комма в ней «раздана» поровну между всеми полутонами. По ней настроены фортепиано и электронные инструменты. |
| **Райд** (ride cymbal) | тарелка со звонким протяжным «динь»; иногда заменяет **хай-хэт**. |
| **Реверберация** (reverb) | эффект «помещения»: звук отражается и плавно затихает, как в большом зале. В Circuit Tracks включается кнопкой FX. |
| **Ритм** (rhythm) | чередование звуков и **пауз** разной длины на фоне ровных **долей**. |
| **Сбивка** (drum fill) | короткая барабанная вставка (часто по **томам**) перед новой частью песни. |
| **Свинг** (swing) | небольшое запаздывание каждого второго шага, из-за которого ровный ритм начинает «раскачиваться». В Circuit Tracks настраивается вместе с темпом. |
| **Секвенсор** (sequencer) | устройство или часть инструмента, которая запоминает, какие ноты и когда играть, и воспроизводит их; делит время на **шаги**. |
| **Секунда** (second) | интервал между соседними ступенями: малая (1 полутон, `до`–`до♯`) и большая (2 полутона, `до`–`ре`). Диссонанс. |
| **Синтезатор** (synthesizer) | инструмент, создающий звук с нуля из электрических колебаний: **осциллятор**, **фильтр**, **усилитель**. |
| **Слоговые названия** (solfège) | `до`, `ре`, `ми`, `фа`, `соль`, `ля`, `си` — названия нот по первым слогам строк средневекового гимна. Приняты в России, Италии, Франции, Испании. |
| **Случайность** (randomness) | приём, при котором нота иногда пропускается, чтобы повтор не звучал механически. В Circuit Tracks задаётся через **Probability**. |
| **Ступень** (scale degree) | порядковый номер ноты в **ладу**: тоника — 1-я, далее до 7-й; после 7-й снова 1-я, на октаву выше. |
| **Сцена** (scene) | в Circuit Tracks: запомненное сочетание **цепочек** всех дорожек, часть песни. |
| **Сэмпл** (sample) | короткая готовая запись звука, например одного удара барабана. Барабанные дорожки Circuit Tracks играют сэмплы. |
| **Сэмплер** (sampler) | инструмент, проигрывающий **сэмплы**. |
| **Такт** (bar, measure) | группа из нескольких **долей**, в электронной музыке почти всегда из четырёх. На Circuit Tracks: 4 доли × 4 **шага** = 16 шагов. |
| **Тембр** (timbre) | «окраска» звука, по которой мы отличаем фортепиано от скрипки на одной и той же ноте. |
| **Темп** (tempo) | скорость музыки, измеряется в **BPM**. |
| **Терция** (third) | интервал через одну ступень: малая (3 полутона, `до`–`ми♭`) и большая (4 полутона, `до`–`ми`). Из двух терций строится трезвучие. |
| **Том** (tom) | барабан ударной установки с различимой высотой: подвесные томы выше, напольный ниже. Используется в **сбивках**. |
| **Тон** (whole tone) | расстояние в два **полутона**: между нотами пропущена одна клавиша (`до`–`ре`). |
| **Тоника** (tonic) | главная нота **лада**, его «дом» (1-я **ступень**). Мелодия, закончившаяся на тонике, звучит завершённо. |
| **Трезвучие** (triad) | **аккорд** из трёх нот лада, взятых через одну (`до`-`ми`-`соль`). Бывает мажорным (светло) и минорным (грустно). |
| **Усилитель** (amplifier) | блок **синтезатора**, решающий, насколько громко звучит нота в каждый момент; его ведёт **огибающая**. |
| **Фильтр** (filter) | блок **синтезатора**, убирающий часть частот: открытый — ярко, закрытый — глухо. |
| **Фраза** (phrase) | законченный кусочек **мелодии**, как предложение в речи. Часто идут парами: **вопрос и ответ**. |
| **Хай-хэт** (hi-hat) | две тарелки на стойке с педалью: сомкнутые дают **закрытый хэт**, разомкнутые — **открытый хэт**. |
| **Цепочка** (chain) | несколько **паттернов** одной дорожки, играющих по очереди. |
| **Частота** (frequency) | число колебаний в секунду, измеряется в герцах (Гц). Чем выше частота, тем выше звук; `ля` первой октавы — 440 Гц. |
| **Четверть** (quarter note) | длительность в одну **долю**: четыре четверти на **такт**. Считается «раз, два, три, четыре». |
| **Четыре на пол** (four on the floor) | **бит**, в котором **бочка** бьёт на каждую **долю**. Основа диско и хауса. |
| **Шаг** (step) | одна клетка **секвенсора**, четверть **доли**. 16 шагов = один **такт**. На шаг ставится удар, нота или **пауза**. |
| **Шестнадцатая** (sixteenth note) | четверть **доли**: 16 на **такт**. Считается «раз-е-и-а, два-е-и-а…». На Circuit Tracks один **шаг** — это шестнадцатая. |
| **Электронная ударная установка** (electronic drum kit) | резиновые **пэды** и педали вместо барабанов и тарелок; звук берётся из памяти и идёт в наушники или колонки. |
